# AI Usage Report

## AI Tool Used

ChatGPT

## What I Asked AI to Do

### 1. Project Planning

I used ChatGPT to understand the Student Support and Ticket Management problem and plan a simple prototype using Python, Streamlit, and SQLite.

### 2. Code Development

I used ChatGPT to generate initial code for:

- Streamlit user interface
- SQLite database setup
- Ticket creation
- Ticket retrieval
- Ticket assignment
- Ticket status updates
- Input validation

### 3. Debugging and Documentation

I used ChatGPT for debugging guidance, testing suggestions, and preparing the project documentation.

## Prompt Most Useful

"Create a simple Student Support and Ticket Management System using Python, Streamlit, and SQLite. Students should be able to create tickets and staff should be able to view, assign, and update ticket status."

## Code Generated by AI

ChatGPT generated initial versions of the application structure and database functions.

The generated code included:

- `app.py`
- `database.py`
- SQLite table creation
- Ticket creation logic
- Ticket retrieval logic
- Ticket assignment and status update logic
- Input validation

## Code I Modified

I reviewed and modified the generated code during development.

I made changes to:

- Ticket categories
- Priority levels
- Staff assignment options
- Ticket status options
- Required-field validation
- Project configuration
- Application testing

## AI Output That Was Wrong or Needed Changes

Some AI-generated suggestions required changes to match the actual project setup and requirements.

## How I Identified the Issues

I identified issues by:

- Running the application locally
- Creating test tickets
- Checking generated ticket IDs
- Testing the Student interface
- Testing the Staff Dashboard
- Updating ticket assignments
- Updating ticket statuses
- Checking the application behavior

## How I Fixed Them

I modified the code based on the results of testing and then ran the application again to verify the changes.

## Validation

AI-generated code was reviewed and tested before being included in the project.

The application was tested locally using sample student information and staff actions.

## Human Contribution

I selected the assignment and technology stack, configured the project, implemented and tested the application, reviewed AI-generated code, made modifications, and validated the working prototype.
