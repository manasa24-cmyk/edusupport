# EduSupport – Student Support & Ticket Management System

EduSupport is a web-based Student Support and Ticket Management System that helps students raise support requests and enables staff to manage, assign, prioritize, process, and resolve those requests.

## Problem Statement

Students may need support for issues related to:

- Fees
- Attendance
- ID Cards
- Documents
- Certificates
- Other administrative matters

EduSupport provides a centralized system for creating and managing these support tickets.

## Features

### Student Features

- Create a new support ticket
- Enter student name and student ID
- Select ticket category
- Select priority
- Enter subject and problem description
- Receive a unique ticket ID

### Staff Features

- View all submitted tickets
- View student and ticket details
- Assign tickets to staff members
- Update ticket status
- Track ticket creation time
- Manage tickets through different workflow stages
